2. Comprobar el `.dusk` con PowerShell, en la carpeta donde se extrajo:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\DEVF_CP01_G2_READ_ONLY_windows-amd64_b3ed281cbcb5934b7a8bd7d78b5adcef19b09ad2.dusk'
```
