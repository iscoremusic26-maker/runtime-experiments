## Integración .dusk y reversión

1. **OFFICIAL_SERVICE**: `FlowService` cuando la operación pertenece a un grafo de diálogo; acciones builtin para flags/switches y callbacks personalizados en el contexto del speaker. El commit valida propietarios de targets y nodos, no el significado narrativo de cada combinación de flags. [sdk/include/mods/svc/flow.h:156](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/sdk/include/mods/svc/flow.h#L156-L179), [src/dusk/mods/svc/flow.cpp:1167](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/src/dusk/mods/svc/flow.cpp#L1167-L1207).
2. **OFFICIAL_SERVICE**: `SaveService` para estado propio del mod. Sus blobs no son una API para cambiar libremente save flags vanilla. [sdk/include/mods/svc/save.h:17](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/sdk/include/mods/svc/save.h#L17-L64).
3. **POTENTIAL_REQUIRES_VERIFICATION**: funciones C++ de dominio para usos fuera del flujo oficial, tras resolver firma/símbolo/game ABI y momento. `GameService` solo contiene cabecera de época ABI; no proporciona métodos de flags. [sdk/include/mods/svc/game.h:9](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/sdk/include/mods/svc/game.h#L9-L26).

Retirar un grafo elimina su integración futura, pero **no revierte por sí mismo flags que su ejecución ya escribió** (`STATIC_INFERRED`: los setters modifican estado y remove_mod elimina registros). Restaurar a ciegas un snapshot antiguo puede deshacer progreso legítimo adquirido después. Por eso el rollback de registros, el de estado temporal y el de progreso persistente son problemas distintos. [src/d/d_save.cpp:1231](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/src/d/d_save.cpp#L1231-L1249), [src/dusk/mods/svc/flow.cpp:654](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/src/dusk/mods/svc/flow.cpp#L654-L701).
