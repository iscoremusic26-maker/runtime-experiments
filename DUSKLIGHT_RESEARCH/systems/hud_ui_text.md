Fuente: `TwilitRealm/dusklight@40457c6adb381928e4b5fef6ed459ed291edd5e2`. Objetivo: Dusklight 2.0.3, Windows x64, DX12, GZ2E01. Esta ficha registra inspección estática; no se ejecutó el juego ni un mod. Los símbolos del juego que aparecen aquí no tienen disponibilidad de enlace ni hook demostrada por su mera existencia.

## HUD original y estado

`dMeter2_c::_create` inicializa estado desde save/play: vida, aceite, oxígeno, rupias, inventario y equipamiento. `_execute` cambia al heap del HUD, comprueba estado, ejecuta `mpMeterDraw` y actualiza medidores/botones. Contiene reconciliación de flags de colección con eventos; no es una capa exclusivamente visual. `_draw` encola mapa/subcontenidos/HUD, pero TARGET_PC omite dibujo por recordingMode/minimalHUD/debugFlyCam. `_delete` elimina subobjetos y heaps propios. **PRES-019**: [src/d/d_meter2.cpp](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/src/d/d_meter2.cpp#L69-L170); [src/d/d_meter2.cpp](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/src/d/d_meter2.cpp#L268-L301); [src/d/d_meter2.cpp](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/src/d/d_meter2.cpp#L347-L435).

Por ello cambiar solo el dibujo no necesariamente cambia la fuente de verdad de inventario/vida, y modificar save para producir un efecto visual puede tener consecuencias persistentes. Véanse [inventario](inventory_equipment.md), [guardado](save_load.md), [progresión](flags_events_progression.md). `UiService` para UI del mod, `WindowService` para ventana y Gfx antes/después del HUD son rutas oficiales distintas del actor `dMeter2`; su matriz está en [SDK](../SDK_AND_SERVICES.md). No asumir que `UiService` reemplaza panes J2D del juego.

## Mensajes: contrato existente

`MessageService.override_message` valida grupo, rango de ID y texto codificado; copia bytes y produce handle owned. La variante callback conserva fn/user_data, no sus objetos externos. `valid_encoded_text` exige terminador al final, tamaños de tags válidos y restricciones para color; no es un traductor genérico de string UTF-8. Resolución busca `(group,id,active_language)`, prioriza mod posterior y secuencia posterior; callback aceptado se copia a vector compartido, texto mal formado falla el mod. **PRES-020**: [src/dusk/mods/svc/flow.cpp](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/src/dusk/mods/svc/flow.cpp#L455-L481); [src/dusk/mods/svc/flow.cpp](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/src/dusk/mods/svc/flow.cpp#L514-L566); [src/dusk/mods/svc/flow.cpp](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/src/dusk/mods/svc/flow.cpp#L1272-L1315).

`register_message` crea ID del pool custom y variantes por idioma; devuelve `MOD_UNAVAILABLE` si agota el pool y rechaza datos inválidos/idiomas duplicados. `resolve_message_entry` valida que el grupo exista y que la variante activa esté presente; no inventa fallback universal. **SOURCE_OBSERVED**: [src/dusk/mods/svc/flow.cpp](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/src/dusk/mods/svc/flow.cpp#L814-L837); [src/dusk/mods/svc/flow.cpp](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/src/dusk/mods/svc/flow.cpp#L1337-L1373). Para navegación y acciones de diálogo véase [cutscenes/dialogue](cutscenes_dialogue.md).

## Idioma del disco y assets

`dusk::language::available_languages` depende de región, plataforma y revisión; Norteamérica ofrece English salvo Wii revision2, que añade French/Spanish. La selección de `msg_folder` utiliza Msgde/Msgfr/Msgsp/Msgit/Msgjp o Msgus/Msguk según idioma/región. Esto no demuestra que un disco GZ2E01 contenga cada variante ni cada glifo; no inferir paridad Wii/GC. **PRES-021**: [src/dusk/language.cpp](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/src/dusk/language.cpp#L8-L38); [src/dusk/language.cpp](https://github.com/TwilitRealm/dusklight/blob/40457c6adb381928e4b5fef6ed459ed291edd5e2/src/dusk/language.cpp#L59-L76).

Integración: `OFFICIAL_SERVICE` para mensajes y UI custom; `ASSET_OVERLAY` para recursos de layout/font compatibles; modificación directa del HUD/J2D sigue `POTENTIAL_REQUIRES_VERIFICATION`. Retirar overrides y callbacks propios antes de unload; esperar nueva resolución de mensajes/recarga de recursos para consumidores ya vivos. **Pendiente**: decodificación BMG por charset completo, J2D layout/font lifecycle, binding de botones y todas las pantallas de menú.
